# ブログ構造監査（2026-05-07）

Gate A（ブログのブランディング水準）の構造観点監査。
対象: 公開中ブログ32本、ブログTOP、記事ページ、`/about`、`/philosophy` との一貫性。

## 現状サマリ

### 構造資産（できていること）

- ブログTOP: PublicHero + Breadcrumb + カテゴリフィルター + 記事リスト
- 記事ページ: バッジ・取材担当アイコン・本文・「Made with Insight Cast」CTA・ShareButtons・前後記事ナビ・関連記事
- JSON-LD: BreadcrumbList・Article・Blog の構造化データを各ページで出力
- フィルター: 6カテゴリのタブ（ノウハウ / サービス / インタビュー / 事例 / 思想 / お知らせ）
- RSSフィード: `feed.xml/route.ts` あり

---

## 検出した構造問題

### 🔴 Blocker（Gate A 達成を直接阻害）

#### B1. カテゴリ正規化で 21/32 (66%) が `service` に集中

DB の生カテゴリ分布:

| カテゴリ | 本数 |
|---|---|
| `insight-cast` | 19（legacy → `service` に正規化） |
| `interview` | 6 |
| `howto` | 2 |
| `service` | 2 |
| `case` | 2 |
| `philosophy` | 1 |
| `news` | 0 |

**正規化後**: `service` カテゴリが 21本（66%）。**カテゴリフィルターが機能していない**（66%が同じタブに入る）。

修正方針:
- 5系統トピック（①AI検索 ②一次情報 ③キャラ ④HP更新リアル ⑤メタ）に合わせて新カテゴリ体系を設計
- DB に新しい category 値を追加する移行が必要（マイグレーション + 既存32本の再カテゴライズ）
- 棚卸し（`ops/blog-taxonomy-2026-05-07.md`）の主タグをそのまま DB に流用するのが最小コスト

#### B2. `news` フィルタータブが記事ゼロなのに残っている

`BlogClient.tsx:19` に `news: お知らせ` タブがあるが該当記事ゼロ → 押すと「このカテゴリの記事はまだありません」。**ブランディング媒体としては「準備中」表示と同じく信用を落とす**。

修正方針:
- 短期: `news` タブを FILTER_TABS から削除
- 中期: B1 のカテゴリ再設計と同時に整理

#### B3. `/about` `/philosophy` ↔ `/blog` の相互リンクがゼロ

grep 結果:
- `/about` `/philosophy` から `/blog` への参照: **0件**
- `/blog` 系列から `/about` `/philosophy` への参照: **0件**（記事末CTAは `/auth/signup` のみ）

特に `/philosophy` は **「AI検索時代に、一次情報だけが残る理由」「なぜインタビューで、価値が引き出せるのか」「なぜホームページの更新は止まるのか」** という、blog の中核思想をそのまま語っているページ。**ブログ ①②系統と完全に重なる内容なのに相互参照なし**。

世界観の一体感が断絶している。Gate A の「`/about` `/philosophy` と blog の世界観が一本に繋がっている」要件を直撃で満たせていない。

修正方針:
- `/philosophy` の各セクション末尾に「この考え方を深掘りした記事」として blog 個別記事へのリンクを2-3本ずつ（特に主タグ ①② の8本を活用）
- `/about` の本文に「思想を読む → /philosophy」「最近の発信を読む → /blog」のテキストリンク
- ブログTOP（PublicHero の aside など）に「Insight Cast の考え方を読む → /philosophy」「私たちについて → /about」を追加
- 記事末CTAに「思想を読む」「Insight Cast について」を追加（後述 S4）

### 🟡 Should Fix（ブランディング水準を下げる構造問題）

#### S1. 7本に interviewer 未設定 → 「Made with Insight Cast」CTAが消える

`app/(site)/blog/[slug]/page.tsx:308` の `{interviewer && (() => {...})()}` により、**interviewer 未設定の記事ではCTAが表示されない**。32本中7本が該当。

修正方針:
- interviewer 未設定でも **代替CTA を必ず表示する**（例: 「Insight Cast について見る → /about」「無料で試す → /auth/signup」）
- もしくは「Made with Insight Cast」を ジェネリック版（キャラなし）にフォールバック

#### S2. 関連記事ロジックが category 一致のみ

`lib/blog-posts.ts:71-75` の `getRelatedPostsFromList` は **category が同じものから先頭3本をslice**。**21本ある `service` カテゴリ内でほぼランダム選択**になり、記事の主旨と関係ない記事が並ぶ可能性が高い。

修正方針:
- B1 のカテゴリ再設計後に効果が出る
- 暫定: interviewer 一致 → category 一致 → 公開日近接 の優先順位で類似度計算
- 中期: blog_posts に topic タグ列を追加し、棚卸し結果を活用

#### S3. コッコ0本・モグロ1本 → 「6キャラ全員働いている」状態に見えない

interviewer 分布:

| キャラ | 本数 |
|---|---|
| ミント | 10 |
| クラウス | 6 |
| レイン | 5 |
| ハル | 3 |
| モグロ | 1 |
| コッコ | **0** |

CLAUDE.md「キャラは機能であって装飾ではない」の文脈で、**コッコ・モグロが記事に出てこない＝6人体制が見えない**。

修正方針:
- 強化テーマ執筆時にコッコ（宣伝・キャンペーン）とモグロ（はい/いいえ深掘り）の取材視点で1本ずつ書く
- もしくは既存記事の interviewer 割当を見直し（誤割当があるかも）

#### S4. 記事末CTA が /auth/signup のみ

「Made with Insight Cast」セクションの唯一の導線が「あなたも試してみる → /auth/signup」。**ブランディング目的のブログにいきなりサインアップ誘導は強すぎる**。philosophy / about / 他記事 への階段がない。

修正方針:
- CTAブロックを2-3導線に分ける:
  - 一次情報の考え方を読む → /philosophy
  - Insight Cast について知る → /about
  - 無料で試す → /auth/signup（既存）
- 階段の温度感を下げる

### 🟢 Nice to Have（今すぐではないが磨きどころ）

## 提案する着手順

1. **B2 `news` タブ削除**（10分・即効）
2. **B3 `/about` `/philosophy` ↔ `/blog` 相互リンク**（3-4時間・世界観の一体感を作る本丸）
3. **S4 + S1 記事末CTA拡充**（1-2時間・全記事に効果が波及）
4. **B1 カテゴリ再設計**（半日仕事・棚卸し主タグを DB に流用）
5. **S2 関連記事ロジック改善**（カテゴリ再設計後に最大効果）
6. **S3 コッコ・モグロ記事**（次の強化テーマ執筆と一緒に）

ステップ1〜3 は **数時間で完了** し、Gate A の「構造」「外形」要件をかなり押し上げられる。
ステップ4は最大効果だが、DB変更とタグ更新を伴うため **マーケター主導で再カテゴライズ方針が決まってから着手**。
